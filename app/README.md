# GroupPulse — דמו חי לאקספו

מוצר עובד: הכתבת סיכום מפגש קבוצתי → טיוטת SOAP קבוצתית + רשומה אישית לכל משתתף + "חוט הזהב" ליעדי תוכנית הטיפול, עם אישור וחתימת מטפל (Human-in-the-loop) וזיהוי מצבי משבר.

## הפעלה
לחיצה כפולה על `start.bat` — נפתח דפדפן בכתובת http://localhost:8765
(נדרש Node מותקן; המיקרופון עובד רק ב-Chrome/Edge דרך localhost.)

## תסריט הדגמה מומלץ (2–3 דקות)
1. **לוח בקרה** → "סכם מפגש חדש".
2. במסך ההכתבה: ללחוץ על המיקרופון ולדבר בעברית (זיהוי דיבור חי), **או** ללחוץ "טען דיקטציה לדוגמה" אם רועש באולם.
3. "צור טיוטות סיכום" → אנימציית עיבוד → מסך התוצאות: סיכום SOAP קבוצתי + טאב לכל משתתף עם "חוט הזהב".
4. לערוך טיוטה, ללחוץ "אשר וחתום" — להראות שכפתור התיוק נפתח רק אחרי אישור **כל** הרשומות.
5. אפקט "וואו": "⚠️ דוגמה עם זיהוי מצב משבר" — מציג התראת בטיחות אדומה ודגל ברשומה של אבי.

## קיצורי דרך
- `http://localhost:8765/?demo=1` — מריץ את כל התהליך אוטומטית (טוב ללולאת תצוגה בעמדה).
- `http://localhost:8765/?demo=crisis` — אותו דבר עם תרחיש משבר.

## מצבי מנוע
- **ברירת מחדל — סימולציה**: עובד תמיד, בלי אינטרנט ובלי עלות. בטוח לאקספו.
- **AI חי**: בתפריט "הגדרות" מדביקים מפתח Anthropic (`sk-ant-...`) — הטיוטות נוצרות בזמן אמת על ידי Claude. בכל שגיאה/ניתוק יש נפילה אוטומטית לסימולציה.

## הערות
- הכל בצד לקוח; אין שמירת אודיו (תמלול דפדפן בלבד) ואין שרת נתונים — תואם למסר הפרטיות של המוצר.
- הנתונים (קבוצה, משתתפים, יעדים) ב-`data.js` — קל לערוך לפני האירוע.
