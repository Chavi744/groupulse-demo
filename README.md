# GroupPulse — מבנה הפרויקט

עוזר תיעוד AI מאובטח לטיפול קבוצתי בבריאות הנפש. הכתבת מטפל לאחר מפגש → סיכום SOAP קבוצתי + רשומה אישית לכל משתתף, מקושרים לתוכנית הטיפול ("חוט הזהב").

| תיקייה | מה יש בה |
|---|---|
| **`app/`** | 🎯 **הדמו החי לאקספו** — אפליקציה עובדת (עברית RTL). הפעלה: לחיצה כפולה על `app\start.bat` → http://localhost:8765. תסריט הדגמה ב-`app/README.md`. זו התיקייה היחידה שבמעקב גיט. |
| `product/` | שלד MVP מבוסס-שרת (Node) — תשתית למוצר האמיתי |
| `landing-page/` | דף הנחיתה החי לרישום בטא (ריפו גיט עצמאי) + QR |
| `docs/` | מסמכים עסקיים: תקציר מנהלים, מודל עסקי, מצגת פיץ' (PDF, עברית) |
| `design/` | מוקאפים: `app-mockups` (דסקטופ), `app-mockups-mobile` / `-en` (מובייל), `mockup-exports` (תמונות PNG), גרסת דף נחיתה ישנה, לוגו |
| `video/` | סרטוני הסבר (MP4) + `video-build/` — כלי הפקת הסרטון (סצנות, קריינות) |

## הפעלה מהירה של הדמו
1. `app\start.bat` (נדרש Node; מיקרופון עובד ב-Chrome/Edge)
2. קיצורים לעמדת תצוגה: `?demo=1` (תהליך מלא אוטומטי), `?demo=crisis` (תרחיש זיהוי משבר)
